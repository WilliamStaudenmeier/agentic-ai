# Agentic AI

An interactive, deterministic multi-agent simulation built with React, TypeScript, Vite, and Radix UI. It demonstrates planning, delegation, tool use, and review without calling an AI model or external API.

## Development

```bash
npm install
npm run dev
```

## Validation

```bash
npm run lint
npm run build
```

## Deploy to Vercel

Import this GitHub repository in Vercel. The Vite defaults are detected automatically:

- Build command: `npm run build`
- Output directory: `dist`
- Install command: `npm install`

Every push to `main` will create a production deployment once the repository is connected to Vercel.
